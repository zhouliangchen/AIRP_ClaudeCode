# 话本 RP

话本 RP 是一个本地运行的 AI 角色扮演工具。你可以用一张 SillyTavern 角色卡、一组文本资料，或一个空白文件夹开始游玩；系统会在浏览器中提供剧情正文、行动输入、状态面板、插图和移动端访问界面。

项目的目标是把角色扮演体验放在一个可持续保存的本地存档里：聊天记录、角色记忆、世界状态、插图资源和个性化 UI 都跟随同一个存档文件夹保存。再次打开同一文件夹时，可以接着上次的剧情继续玩。

## 适合什么场景

- 想把 SillyTavern 角色卡或世界书作为长线 RP 存档继续游玩。
- 想从小说、设定集或空白开局逐步生成角色、世界和剧情。
- 想在电脑上运行，在手机或平板上通过同一局域网访问前端。
- 想让剧情过程中自动整理角色记忆，并按需生成剧情插图或存档专属 UI。

## 准备环境

请在 Windows PowerShell 中操作。

1. 安装 Python 3、Node.js 和 Git。
2. 安装并登录可用的 Claude Code。
3. 克隆或下载本项目。
4. 在项目根目录运行一次：

```powershell
.\setup-claude-code.bat
```

脚本会检查本机环境和 Claude Code 命令是否可用。

## 快速开始

1. 在项目根目录或任意合适位置新建一个存档文件夹，例如 `我的角色\`。
2. 可选：把 SillyTavern PNG 角色卡、世界书 `.json`、小说或设定资料 `.txt` / `.md` 放进这个文件夹。
3. 进入该存档文件夹，启动 Claude Code：

```powershell
claude
```

4. 在 Claude Code 中输入：

```text
/rp
```

5. 按启动提示打开浏览器页面，默认本机地址是：

```text
http://localhost:8765
```

再次游玩同一存档时，仍进入同一个存档文件夹启动 `claude` 并运行 `/rp`。系统会读取已有记录继续剧情。

## 启动方式

本项目支持四种常见启动方式：

- **角色卡启动**：把 SillyTavern PNG 角色卡放入存档文件夹，系统会导入角色设定、开场、世界书和可用图片资源。
- **文本资料启动**：把小说、设定集、世界观资料或角色资料放入存档文件夹，系统会尝试整理为可游玩的存档。
- **旧存档继续**：存档文件夹已有聊天记录和记忆文件时，会继续上次进度。
- **空白启动**：文件夹没有可导入素材时，会进入空白模式，由你在第一轮输入中设定开局。

空白模式不会自动生成开场。你可以直接在浏览器里写下角色身份、场景、目标或第一段行动。

## 浏览器使用

浏览器页面会显示：

- 剧情正文和已生成插图。
- 当前运行状态和待生成图片数量。
- 玩家输入框和行动建议。
- 文风、字数、NSFW、自我修复、调试模式和 API 设置等选项。
- 桌面端侧边栏和移动端设置面板。

玩家输入分为两个用途：

- **角色输入**：以你正在扮演的角色视角行动、说话或引导接下来的剧情。
- **系统指令**：提出设置调整、剧情修正、UI/插图需求、数据修改或其他明确指令。

普通游玩时只写角色输入即可。需要改设定、改画风、请求插图或处理问题时，再使用系统指令。

## 模型与 API 设置

运行时需要可用的文本模型。默认推荐使用 cc_switch / Claude Code 本地反代；也可以在前端 API 设置页配置 OpenAI-compatible 文本 API。

图片生成功能使用独立的 OpenAI-compatible 图片生成 API。没有配置图片 API 时，正文 RP 仍可运行，图片任务会保持等待或暂缓状态。

可在浏览器侧边栏的 **API 设置** 中配置：

- cc_switch 服务地址。
- OpenAI-compatible 文本 API。
- 图片生成 API。

前端 API 设置会保存到 `skills/styles/llm_settings.frontend.json`；本地兜底 API 配置文件是 `skills/styles/llm_settings.local.json`。配置优先级为：前端设置 > 环境变量 > 本地配置文件。图片生成 API 可额外填写 `image_generation.fallback` 作为备用接口。

本地配置文件示例：

```json
{
  "cc_switch": {
    "enabled": true,
    "service_url": "http://127.0.0.1:15721"
  },
  "openai_compatible": {
    "enabled": false,
    "core": {"base_url": "", "api_key": "", "model": ""},
    "review": {"base_url": "", "api_key": "", "model": ""},
    "actor": {"base_url": "", "api_key": "", "model": ""}
  },
  "image_generation": {
    "base_url": "",
    "api_key": "",
    "model": "",
    "fallback": {
      "base_url": "",
      "api_key": "",
      "model": ""
    }
  }
}
```

也可以使用环境变量配置。常用变量包括：

```powershell
$env:AIRP_CC_SWITCH_ENABLED="true"
$env:AIRP_CC_SWITCH_SERVICE_URL="http://127.0.0.1:15721"
$env:AIRP_IMAGE_GENERATION_BASE_URL="https://..."
$env:AIRP_IMAGE_GENERATION_API_KEY="sk-..."
$env:AIRP_IMAGE_GENERATION_MODEL="..."
$env:AIRP_IMAGE_GENERATION_FALLBACK_BASE_URL="https://..."
$env:AIRP_IMAGE_GENERATION_FALLBACK_API_KEY="sk-..."
$env:AIRP_IMAGE_GENERATION_FALLBACK_MODEL="..."
```

## 图片与个性化 UI

剧情过程中可以自动或按你的要求生成插图。插图会显示在对应剧情轮次中；用于保持角色一致性的人设参考图只作为绘图素材保存，不会直接显示在正文里。

你可以在系统指令中提出类似需求：

```text
以后每轮都生成一张剧情插图，画风偏细腻日系小说插画。
```

```text
为当前场景生成一张雨夜街角的氛围插图，不需要出现角色。
```

```text
把画风调整为冷色、电影感、低饱和，并保持后续插图一致。
```

图片生成是异步任务，不会阻塞已经完成的正文交付。顶部状态栏会显示当前运行状态和待生成图片数量。

## 局域网访问

默认服务会监听本机网络，便于手机、平板或其他同一局域网设备访问。启动后终端会显示局域网地址，通常类似：

```text
http://<本机局域网IP>:8765
```

如果手机打不开：

- 确认手机和电脑在同一网络。
- 确认 Windows 防火墙允许 Python 入站连接。
- 如只想允许本机访问，可在启动前设置：

```powershell
$env:AIRP_HOST="127.0.0.1"
```

## 数据与安全

每个存档文件夹会保存聊天记录、角色记忆、生成图片、运行状态和本地设置。请不要把自己的存档、密钥或生成资源提交到公开仓库。

常见的本地数据包括：

- 聊天记录和玩家输入。
- 角色长期记忆、重点记忆和短期记忆。
- 世界状态和剧情摘要。
- 生成图片和存档级 UI 文件。
- 本地 API 配置和调试日志。

如果要分享项目代码，请先确认没有包含自己的存档文件夹、API key 或调试日志。

## 常见问题

**打开网页后显示无法访问**

先确认 `/rp` 已经启动本地服务，再打开 `http://localhost:8765`。如果端口被占用，关闭旧的 Python/Node 测试进程后重试。

**模型没有回复或一直等待**

检查 API 设置页中的文本模型配置，确认 cc_switch 或 OpenAI-compatible 文本 API 可用。

**图片没有生成**

检查图片生成 API 是否配置完整。若已配置备用图片 API，主接口不可用时会自动尝试备用接口，并在 API 设置页显示提示。正文可以正常交付时，图片任务仍可能因为缺少图片 API、缺少参考图或底层 provider 不支持参考图而暂缓。

**移动端打不开局域网地址**

确认电脑和移动设备在同一局域网，并允许 Windows 防火墙中的 Python 入站连接。

**想从空白卡开始**

创建一个空文件夹，在其中运行 `claude` 和 `/rp`。第一轮输入中说明主角、场景和你希望开始的事件即可。
